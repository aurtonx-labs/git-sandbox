# 🧪 Git Sandbox & Experimentation Lab

A safe space to learn, break, and master Git version control concepts.

- [ ] Basic commands (`commit`, `push`, `pull`, `status`)
- [ ] Branch management (`git checkout -b`, feature branching)
- [ ] Merge strategies & resolving merge conflicts
- [ ] Rewriting history (`git rebase`, `git commit --amend`, `cherry-pick`)
- [ ] Stashing uncommitted changes (`git stash`)
- [ ] Tagging releases (`git tag`)
